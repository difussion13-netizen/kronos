# bench/latency_bench.py — чем мерить «самую быструю локацию»

Одиночный файл на чистом Python (без зависимостей). Меряет задержки до API,
которые реально важны будущему торговому боту: REST (CLOB /time, Gamma, geoblock,
Binance /time) и — с ключом `--ws` — websocket-подключения (рукопожатие +
время до первого сообщения). Ничего никуда не отправляет.

## Запуск на сервере (Session Manager, как для логгера)

```bash
curl -sL -o /tmp/bench.py https://raw.githubusercontent.com/difussion13-netizen/kronos/arena/01a063d9-kronos/bench/latency_bench.py
python3 /tmp/bench.py --ws
```

Должна появиться таблица:

```
TARGET          n  tcp ms p50(min) tls     ttfb ms p50   TOTAL ms p50  mean±sd   errs edge
fake            10      1.9(1.6)    3.8       28.4        30.1    31.2±2.4   0   104.18.34.205
...
clob_ws        handshake 7.9 ms (tcp 1.9 + tls 4.0 + up 2.0)  first_frame 41 ms tokens=16
```

## Как сравнивать локации (расследование на 15 минут и ~$0.10)

1. В консоли AWS создай по одному самому дешёвому серверу в регионах-кандидатах
   (t3.micro, spot, 8 ГБ): `eu-west-1` (Дублин), `eu-west-2` (Лондон),
   `us-east-1` (Вирджиния) — при желании ещё `eu-central-1` (Франкфурт) и
   `ap-northeast-1` (Токио). Переключать регион — кнопкой справа вверху; сервер
   создаётся в текущем выбранном регионе.
2. На каждом: та же пара строк curl+python из блока выше, плюс сохранение:
   `python3 /tmp/bench.py --ws --json > bench-дублин.json` (имя — своё).
3. Таблицы (или json'ы) прислать мне — сведу.
4. Все тестовые серверы **закрыть (Terminate)** — иначе они тикают деньгами.

## Что означают числа (важно!)

- REST и WS идут **через край Cloudflare**, ближайший к тебе. Поэтому колонка
  `tcp` ≈ «до края», а не «до биржи» — по ней регионы не различаются.
- Различается колонка `TOTAL` и WS `first_frame`: в них сидит путь
  «край CDN → origin в Лондоне». Из Дублина/Лондона там будет +1–3 мс, из
  Вирджинии +70 мс, из Азии больше. Разница в `TOTAL` между регионами — это и
  есть реальная разница, которую почувствует бот.
- `geoblock` в таблице — «как нас видит биржа». Для торговли годятся страны,
  которых нет в close-only-списке API (Ирландия — годится; флаг `blocked:true`
  при `country:IE` — норма, он про веб-фронтир).
- `errs`>0 и пустые строки (binance из некоторых регионов) — просто связь
  фильтруется, не пугайся.

## Ключи

```
--reps N        сколько замеров (10 по умолчанию; для спокойных сравнений — 20)
--warmup N      сколько «прогревочных» выбросить (2)
--timeout S     секунд на операцию (8)
--only a,b      конкретные мишени (clob_time,gamma_market,geoblock,binance_time)
--ws            добавить websocket-тесты (главное для бота)
--json          машиночитаемый вывод (для меня)
--tag ИМЯ       подпись локации в выводе
--url name=host[:port]/path   своя мишень (для тестов/других сервисов)
```
