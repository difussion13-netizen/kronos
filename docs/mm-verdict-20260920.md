1) MM-медианы по факту меряются «btc все 13 суток + eth/sol/xrp ~9 суток» —

   а не пересчёта — минутки для этих суток не в CLOB-архиве.

## Что это значит
1. **Знак, а не ёмкость.** Снятия ограничения участия хватает, чтобы P&L стал
   ХУЖЕ вдвое (−253k → open хуже на всех срезах): «нам не хватило ликвидности»
   опровергнуто на обоих длинах периода.
2. **Прокси-ярлык даёт артефакт ×4–5.** Те же окна: +7.27¢ по клиновому прокси
   против −20…−25¢ по платежу площадки. Гейты M1–M4, снятые без `--venue-cache`,
   — «ДА» как артефакт конвенции «100 акций на касание»; выводы по ним запрещены.
3. **M3 провален полностью: 0/13 (0/11 на 11-суточном срезе)** — якорный центр
   хуже нейтрального 0.5 на всём периоде. Направление сдвига центра против
   платёжа. Нейтральный контроль имеет P&L > 0 при ОТРИЦАТЕЛЬНОЙ медиане markout
   ⇒ на этой конвенции P&L чувствителен к правилам резолва; сопоставимы только
   markout-медианы — а они отрицательны везде.
4. **Живой журнал подтверждает:** K-гейт (`src="resolve"`, только K) — медиана
   −12.62¢ на n=146, EV<0 во всех бинах (снимок до финального архива журнала;
   итоговое число фиксировалось последним прогоном K/L перед остановкой
   трейдера).

## Не является основанием для продолжения
- Модель очереди / пересечения t1–t2: в снапшотах нет ни очереди, ни объёма
  агрессора; M6-уточнение меняет только верхнюю границу, которая и так красная.
- Увеличение размера / ослабление max_part: см. пункт 1.
- «Суток было мало»: 13 суток при 1с-кэше и живой день-сборке уже в деле;
  следующие сутки двигают ДИ вокруг отрицательной медианы, не знак.
